# Coding assistant rules

These rules apply to every AI coding assistant working in this repo (Antigravity/Gemini, Cursor, Claude, etc.).

1. **Ask instead of assuming.** If requirements are unclear or ambiguous, ask before writing code.
2. **Keep changes minimal.** Make the smallest change that solves the problem. Don't turn 50 lines into 300.
3. **Don't touch code that wasn't asked about.** No drive-by refactors, renames, reformatting, or "improvements" outside the request.
4. **Verify before saying done.** Run the build, tests, or the app and confirm it works before reporting the task complete.
